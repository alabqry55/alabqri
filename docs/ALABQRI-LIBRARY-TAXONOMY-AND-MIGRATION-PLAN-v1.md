## 1. الغرض والنتيجة المطلوبة

تضع هذه الوثيقة نموذجًا موحدًا لتنظيم مكتبة ALABQRI، بحيث يمكن توزيع المقالات والأبحاث والمراجع والمواد التعليمية على أقسام رئيسية واضحة، وربطها بالتخصصات الدقيقة، وتصنيف نوع المحتوى، وإضافة الوسوم دون خلط هذه المستويات بعضها ببعض.

النتيجة المستهدفة:
1. سبعة أقسام رئيسية ثابتة بترتيب معتمد.
2. أربعة عشر تخصصًا موضوعيًا مقترحًا، لكل منها تعريف وحدود.
3. مصفوفة تربط كل تخصص بقسمه الأساسي والأقسام ذات الصلة.
4. قواعد إسناد واضحة تمنع التكرار والتصنيف الاعتباطي.
5. فصل القسم عن التخصص ونوع المحتوى والوسوم والبرنامج التدريبي.
6. خطة آمنة لجرد التصنيفات القديمة وتحويلها تدريجيًا بعد مراجعة كل مادة.
7. أساس قابل للتوسع لموسوعة العبقري والبحث والتعليم والمساعد الذكي.

**لا تعني هذه الوثيقة اعتمادًا علميًا أو شرعيًا أو طبيًا للمصطلحات الواردة في قائمة التخصصات.** وهي تميز بين دراسة المفاهيم والممارسات التراثية أو التكميلية وبين ثبوت الفاعلية السريرية.

## 2. المبادئ الحاكمة

- القسم الرئيسي يجيب: «في أي مجال عام أبحث؟».
- التخصص يجيب: «ما الموضوع الدقيق لهذه المادة؟».
- نوع المحتوى يجيب: «ما طبيعة المادة المنشورة؟».
- الوسوم تساعد في البحث والربط ولا تحل محل القسم أو التخصص.
- البرنامج أو الدبلومة كيان تعليمي مستقل، وليس تصنيفًا للمقال.
- لكل مادة قسم رئيسي واحد أساسي، وتخصص أساسي واحد عند انطباقه؛ ويمكن إضافة علاقات ثانوية محدودة ومبررة.
- لا يُفرض تخصص على مادة لا ينطبق عليها أي تخصص؛ يجوز أن تبقى المادة في قسمها مع تخصص «غير محدد» إلى حين المراجعة.
- لا يُستنتج القسم الجديد من اسم القسم القديم وحده؛ العنوان والملخص والمحتوى والمصادر هي أساس القرار.
- لا تُحذف المعرفات أو الروابط أو السجلات القديمة، ولا يعاد استخدام slug لمادة أخرى.
- يبقى ترتيب الأقسام السبعة ثابتًا في واجهة المكتبة ما لم يصدر قرار تحريري لاحق.

## 3. الأقسام الرئيسية السبعة المعتمدة في هذا التصور

| الرمز | القسم الرئيسي | نطاقه التحريري |
|---|---|---|
| CAT-01 | القرآن الكريم وعلومه | التفسير وعلوم القرآن والتدبر المنضبط والبيان والإعجاز وفق مناهج موثقة. |
| CAT-02 | الحديث الشريف وعلومه | السنة النبوية ومصطلح الحديث والتخريج والشروح والسيرة والهدي النبوي. |
| CAT-03 | الذكر والإتزان الإيماني | الأذكار والأدعية والرقائق والعبادات والتزكية والسكينة ذات التأصيل الشرعي. |
| CAT-04 | علم النفس الإسلامي والتنمية البشرية | التثقيف النفسي والأسري والتربوي والمهارات والتنمية والسلوك وجودة الحياة من منظور منضبط. |
| CAT-05 | الطب التكميلي والتوعية الصحية | التثقيف الصحي والممارسات التكميلية والتاريخ الطبي والتأهيل غير السريري ضمن حدود الدليل والاختصاص. |

| CAT-07 | المعرفة والفكر | الفكر والثقافة والتاريخ والمفاهيم والمنهجيات والدراسات المقارنة والقضايا العامة. |

### ملاحظة مهمة حول القسم السادس

«الأبحاث والدراسات» قسم تصفح رئيسي في الواجهة، لكنه ليس نوعًا حصريًا للمحتوى. إذا كانت مادة بحثًا علميًا في موضوع قرآني مثلًا، فيمكن أن يكون قسمها الأساسي «القرآن الكريم وعلومه»، ونوعها «بحث»، مع وسم أو علاقة إضافية تتيح ظهورها ضمن واجهة الأبحاث والدراسات. ويجوز اعتماد القسم السادس أساسيًا عندما يكون محور المادة هو عرض دراسة عابرة للتخصصات أو منهج بحثي عام، وفق سياسة تحريرية موحدة.

### 4.1 قواعد خاصة للتخصصات ذات المصطلحات محل الخلاف

1. «الطاقة الإنسانية/الكونية/الروحية» ثلاثة مسارات تحريرية منفصلة، ولا تُدمج تلقائيًا في مصطلح علمي واحد.
2. يجب توضيح ما إذا كانت المادة تتناول مفهومًا ثقافيًا أو تاريخيًا أو فلسفيًا أو ممارسة تكميلية أو فرضية بحثية.
3. لا توصف الطاقة أو الهالة أو الشاكرات أو الريكي أو اللمسة الشفائية بأنها آليات طبية مثبتة، ولا تنسب إليها معالجة الأمراض دون أدلة سريرية موثوقة.
4. «العلاج عن بعد» ليس تخصصًا متجانسًا؛ يجب تحديد نوع الخدمة ومؤهلات مقدمها وأساسها العلمي والقانوني.
5. لا تمنح المقالات أو الدورات أهلية تشخيص أو علاج الأمراض النفسية أو العضوية، ولا تتجاوز حدود المؤهلات والترخيص المهني.
6. لا تُنسب ممارسة أو دعاء أو اسم أو فضيلة إلى الشرع إلا بمصدر معتبر، ولا تكفي التسمية التسويقية «إسلامي» لإثبات الحكم أو الصحة.

## 5. نموذج البيانات التحريري المقترح لكل مادة

هذه مواصفة مفاهيمية، وليست اقتراحًا نهائيًا لأسماء أعمدة D1 قبل فحص المخطط الحي.

| الحقل المنطقي | الإلزام | الغرض |
|---|---|---|
| معرّف المادة | إلزامي | هوية ثابتة لا تتغير عند تعديل العنوان. |
| العنوان | إلزامي | عنوان المادة المعروض. |
| slug / الرابط | إلزامي بحسب نظام النشر | رابط ثابت مع سياسة تمنع كسر الروابط القديمة. |
| القسم الأساسي | إلزامي | واحد من الأقسام السبعة بعد اعتماد الترحيل. |
| التخصص الأساسي | عند الانطباق | تخصص واحد من القائمة المعتمدة، أو «غير محدد» مؤقتًا. |
| تخصصات مرتبطة | اختياري | علاقات ثانوية متعددة عند وجود مبرر تحريري. |
| نوع المحتوى | إلزامي | مقال، بحث، دراسة، مرجع، مادة تعليمية، مراجعة، دليل، أو غير ذلك. |
| الملخص | موصى به | وصف موجز دقيق للمحتوى. |
| الكلمات المفتاحية/الوسوم | اختياري | استكشاف وبحث؛ لا تستبدل التصنيف. |
| المؤلف/المراجع | بحسب السياسة | نسبة المحتوى ومسؤولية مراجعته. |
| المصادر والمراجع | إلزامي للمحتوى الادعائي/البحثي | توثيق أصل المعلومات. |
| تاريخ النشر والتحديث | بحسب نظام النشر | سجل زمني. |
| الحالة التحريرية | إلزامي داخليًا | مسودة، قيد المراجعة، معتمد للنشر، منشور، مؤرشف. |
| مراجعة السلامة | بحسب الموضوع | علمية/شرعية/طبية/مهنية عند الحاجة. |
| علاقة ببرنامج أو دورة | اختياري | ربط المادة بكيان تعليمي مستقل. |

### 5.1 أنواع المحتوى المقترحة

- مقال تثقيفي.
- بحث علمي.
- دراسة تحليلية أو مقارنة.
- مراجعة أدبيات.
- مرجع أو مادة مرجعية.
- درس أو مادة تعليمية.
- دليل إجرائي.
- فتوى أو نقل شرعي موثق، إذا استوفت سياسة المراجعة والنسبة.
- خبر أو إعلان مؤسسي.
- مادة صوتية أو مرئية مصاحبة.

يمكن تعديل القائمة بعد جرد المحتوى الفعلي. ولا ينبغي إنشاء نوع محتوى لكل تخصص.

## 6. قواعد توزيع المقالات والأبحاث

### 6.1 شجرة القرار

1. اقرأ المادة كاملة أو اقرأ عنوانها وملخصها ومتنها ومراجعها بالقدر الذي يسمح بتحديد موضوعها.
2. حدد السؤال أو الموضوع المركزي، لا الكلمات العابرة أو الوسوم الأكثر تكرارًا.
3. اختر قسمًا أساسيًا واحدًا هو الأقرب إلى الغرض الأساسي للمادة.
4. اختر تخصصًا أساسيًا واحدًا إن انطبق بوضوح.
5. أضف تخصصًا ثانويًا فقط إذا كان جزءًا جوهريًا من المادة، لا لمجرد ذكره.
6. حدد نوع المحتوى مستقلًا.
7. أضف وسومًا محدودة ودقيقة ومتسقة.
8. إذا تعارضت الأدلة أو احتمل المحتوى أكثر من تصنيف، أرسله إلى المراجعة ولا تخمّن.
9. تحقق من ظهور المادة في البحث والروابط والواجهات المقصودة بعد الترحيل التجريبي.

### 6.2 أمثلة تطبيقية إرشادية

| موضوع المادة | القسم الأساسي المرجح | التخصص الأساسي المرجح | نوع المحتوى |
|---|---|---|---|
| تفسير آيات الصبر مع نقل أقوال المفسرين | القرآن الكريم وعلومه | علوم القرآن الكريم | مقال أو دراسة |
| تخريج حديث وشرح درجته | الحديث الشريف وعلومه | علوم السنة النبوية | بحث أو مرجع |
| الفرق بين الخوف والخشية في القرآن | القرآن الكريم وعلومه | علوم القرآن الكريم | مقال |
| فضل الذكر وأثره التعبدي بنصوص ثابتة | الذكر والإتزان الإيماني | علوم الأسماء والدعوات والرقى إذا كان محوره الدعاء/الذكر؛ وإلا يراجع لإسناد تخصص أدق | مقال |
| دراسة نقدية لمفهوم الهالة والطاقة | الأبحاث والدراسات أو المعرفة والفكر بحسب غرض المادة | علوم الطاقة الإنسانية أو الكونية بحسب موضوعها | دراسة تحليلية |
| توعية عن الاسترخاء واللمس الآمن | الطب التكميلي والتوعية الصحية | علوم اللمسة الشفائية إذا كان هذا هو موضوع الدراسة | دليل تثقيفي |
| مهارات التواصل الأسري | علم النفس الإسلامي والتنمية البشرية | علوم الحياة وهندسة الجودة والتوازن الشامل فقط إذا تناولت إطارها فعلًا؛ وإلا تخصص فرعي يحتاج اعتمادًا | مقال أو مادة تعليمية |
| شرح منهج التثبت ومراجعة الادعاءات | المعرفة والفكر | منهج العبقري في سلامة الوصول | دليل منهجي |

الأمثلة لا تمثل إعادة تصنيف لمقالات منشورة؛ هي قواعد توضيحية. ويجب مراجعة المقال الفعلي قبل إسناد أي قيمة.

## 7. العلاقة بين المكتبة والأركان الأخرى

### 7.1 البرامج والدبلومات

البرنامج التدريبي كيان مستقل له معرّف وخطة ومخرجات تعلم وساعات ومراجع وتقييم وشروط قبول ووثائق اعتماد عند وجودها. ويرتبط:
- بقسم رئيسي واحد أو أكثر بحسب سياسة عرض البرامج.
- بتخصص رئيسي واحد أو أكثر.
- بمواد مكتبية داعمة.
- بمراجع ومصادر.
- بنسخة منهج/مقرر محددة.

لا تحول أسماء الدبلومات العشرة الواردة في وثيقة المعمارية إلى أقسام مكتبية. ولا تعتبر وجود صفحة وصفية دليلًا على وجود نظام تسجيل أو اعتماد.

### 7.2 منظومة السكينة والاتزان

ترتبط مواد التثقيف والتطوير بأدوات البوصلة والمصفوفة والمؤشر والخريطة وفق صلة واضحة، لكن لا تُربط نتيجة مستخدم بمقال أو برنامج تلقائيًا دون موافقة وشرح للغرض. وتظل أدوات القياس إرشادية غير تشخيصية وفق الضوابط المعمارية.

### 7.3 مساعد العبقري الذكي

عند بنائه أو تطويره، يجب أن يسترجع المواد من بيانات التصنيف المعتمدة، وأن يعرض:
- عنوان المصدر ورابطه.
- القسم والتخصص ونوع المحتوى.
- تاريخ المراجعة عند توافره.
- حالة المراجعة العلمية/الشرعية/المهنية.
- تنبيهًا واضحًا عندما تكون المادة رأيًا أو ممارسة تقليدية أو ادعاءً غير مثبت.

ولا يستنتج المساعد صحة الادعاء من مجرد وجوده في المكتبة.

## 8. التعامل مع التصنيفات التقنية القديمة الستة

بحسب الجرد البرمجي، القيم الحالية المرصودة في مكتبة المقالات وواجهة API هي:

1. `القرآن الكريم وعلومه`
2. `الأذكار والاتزان`
3. `التنمية البشرية`
4. `الطب التكميلي`
5. `البحث العلمي`
6. `موضوعات معرفية`

وهذه القيم لا تطابق تمامًا الأسماء المستهدفة للأقسام السبعة. كما أن وجود القسم السابع «الحديث الشريف وعلومه» في التصور التحريري لا يعني أنه أصبح قيمة تقنية في API أو قاعدة البيانات.

### 8.1 جدول التحويل الأولي — ليس تحويلًا آليًا

| القيمة القديمة | الوجهة المحتملة | شرط التحويل |
|---|---|---|
| القرآن الكريم وعلومه | CAT-01 | مراجعة المادة للتأكد من كون موضوعها قرآنيًا فعلًا. |
| الأذكار والاتزان | CAT-03 | المواد الحديثية الخالصة قد تنتقل إلى CAT-02 بعد التحقق من محتواها. |
| التنمية البشرية | CAT-04 | المواد النفسية/الأسرية/التربوية؛ أما الموضوعات العامة فقد تناسب CAT-07. |
| الطب التكميلي | CAT-05 | مراجعة نوع الادعاء ومجاله وحدود السلامة؛ المواد النظرية النقدية قد تناسب CAT-06 أو CAT-07. |
| البحث العلمي | لا تحويل ثابت | يعاد تحديد القسم الموضوعي، ويضبط نوع المحتوى «بحث/دراسة» مستقلًا. يمكن إبقاء CAT-06 للمواد البحثية العامة أو العابرة للتخصصات. |
| موضوعات معرفية | CAT-07 غالبًا | بعض المواد قد تنتمي إلى القرآن أو الحديث أو التنمية أو الطب بعد قراءة محتواها. |

### 8.2 قاعدة حاسمة

لا تنفذ عملية من نوع «كل قيمة قديمة تساوي قسمًا جديدًا» على قاعدة البيانات. هذا الجدول يحدد احتمالات فقط. قد تحتوي القيمة القديمة الواحدة على مواد تنتمي إلى أكثر من قسم جديد، وقد تتطلب المادة الواحدة مراجعة متخصصة قبل نقلها.

### 8.3 معالجة القسم الجديد: الحديث الشريف وعلومه

- لا تنشأ له سجلات مصطنعة أو محتويات افتراضية.
- تُراجع المواد الموجودة التي محورها السنة أو الحديث أو التخريج أو الشروح.
- يُفصل الحديث بوصفه موضوعًا أصليًا عن مجرد الاستشهاد بحديث داخل مقال قرآني أو تربوي.
- تُوثق درجة الحديث ومصدره كلما كان ذلك جوهريًا لمضمون المادة.
- لا يعتمد نقل المادة إلى CAT-02 لمجرد وجود حديث واحد في متنها.

## 9. خطة الترحيل الآمن — مراحل لا تتجاوز بعضها

### المرحلة صفر: التثبيت والموافقة التحريرية
- اعتماد أسماء الأقسام السبعة وترتيبها.
- مراجعة تعريفات التخصصات الأربعة عشر وحدودها.
- اعتماد أنواع المحتوى والوسوم.
- تحديد المسؤول عن المراجعة الشرعية والعلمية والطبية والمهنية.
- تسجيل أي تخصص مرفوض أو معاد تسميته أو مؤجل، دون إسقاطه بصمت.

**مخرج المرحلة:** نسخة معتمدة من هذه الوثيقة أو إصدار لاحق موقع/مؤرخ.

### المرحلة 1: جرد قراءة فقط
من اتصال موثوق بقاعدة الإنتاج، وبعد التحقق من البيئة والقاعدة الصحيحة:
- قراءة بنية جدول المقالات والفهارس والعلاقات.
- عدّ المواد بحسب التصنيف الحالي والحالة والنشر.
- استخراج قائمة محدودة من المعرفات والعناوين والتصنيفات والتواريخ.
- جرد التصنيفات غير المعروفة والقيم الفارغة والتكرارات.
- جرد الروابط والـ slugs والتأكد من عدم وجود تصادمات.

لا تنفذ أي INSERT أو UPDATE أو DELETE أو DDL في هذه المرحلة.

### المرحلة 2: ملف خريطة تحويل ومراجعة بشرية
- إنشاء سجل لكل مادة: المعرّف الحالي، العنوان، القيمة القديمة، القسم المقترح، التخصص المقترح، نوع المحتوى المقترح، سبب القرار، المراجع، حالة المراجعة.
- إسناد حالة «مؤكد» أو «بحاجة لمراجعة» أو «غير محسوم».
- مراجعة جميع المواد الملتبسة يدويًا.
- عدم استخدام العنوان وحده كدليل نهائي.
- حفظ نسخة مرجعية من خريطة التحويل قبل أي تغيير.

### المرحلة 3: تصميم تقني على Preview
- مقارنة النموذج المقترح بمخطط D1 الفعلي، لا بـ `schema.sql` وحده.
- اختيار طريقة توسعة متوافقة مع التطبيق الحالي؛ لا يُفرض جدول جديد أو تغيير أعمدة قبل دراسة الاعتماديات.
- الحفاظ على توافق القراءة مع القيم القديمة خلال فترة الانتقال.
- بناء migration قابلة للتكرار الآمن قدر الإمكان، وخطة rollback موثقة.
- تنفيذ التحويل على نسخة اختبار/بيانات تجريبية غير حساسة.
- التحقق من عدد السجلات قبل وبعد، وعدم تغير المعرفات أو العناوين أو الروابط أو المحتوى.

### المرحلة 4: اختبارات وظيفية وأمنية
اختبار:
- قائمة الأقسام السبعة وترتيبها.
- ظهور القسم الثاني «الحديث الشريف وعلومه».
- التصفية حسب القسم والتخصص ونوع المحتوى والوسوم.
- البحث العام والبحث داخل القسم.
- عرض المقال وفتح الرابط القديم.
- إضافة مادة وتعديلها من جلسة المالك فقط.
- رفض أي محاولة إدارة غير مصرح بها.
- منع التكرار وعدم استبدال مادة موجودة عند تعارض الهوية أو العنوان.
- سلامة الهاتف والحاسوب واتجاه RTL.
- عدم تسرب بيانات الإدارة أو النتائج الخاصة.
- عدم حدوث فقد أو تضاعف في سجلات المقالات.

### المرحلة 5: قرار النشر
لا يجرى نشر الإنتاج إلا بعد:
1. نجاح اختبارات المصادقة والإدارة والحفظ والقراءة والتصفية.
2. مراجعة فروق عدد السجلات والروابط.
3. اعتماد خريطة التحويل النهائية.
4. نجاح فحوص الأمان ذات الصلة.
5. وجود نسخة احتياطية قابلة للاستعادة وخطة رجوع مختبرة.
6. موافقة صريحة على نشر التغيير.

إذا فشل أي شرط، يتوقف النشر ويُعالج السبب في Preview.

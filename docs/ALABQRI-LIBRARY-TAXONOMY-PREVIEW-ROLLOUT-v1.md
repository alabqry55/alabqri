# تأسيس التصنيف متعدد المستويات لمكتبة ALABQRI — حزمة Preview v1

- الفرع: `feat/library-taxonomy-preview-foundation`
- نقطة الأساس: `main` عند `19631ae903ff0cbe9aa985a5acea9b06649041fd`
- النطاق: إضافة بنية تصنيف مستقلة دون المساس بجدول `articles`.
- الحالة: Migration 0002 تؤسس القواميس، ثم Migration 0003 تضيف علاقة التخصص بالقسم. يجب تطبيقهما بهذا الترتيب على قاعدة جديدة، أو تطبيق 0003 وحدها على قاعدة قديمة سبق أن أُنشئت فيها الجداول.

## 1. ما الذي أُنشئ؟

ملف التأسيس:
`migrations/0002_library_taxonomy_foundation.sql`

ينشئ:
- `library_sections`: الأقسام السبعة بالترتيب المعتمد.
- `library_specialties`: التخصصات الأربعة عشر، دون عمود ربط القسم في هذه المرحلة.
- `library_content_types`: خمسة أنواع محتوى أساسية.
- `library_article_classification`: علاقة مستقبلية اختيارية بين المقال وتصنيفه.
- `article_admin_audit`: سجل تدقيق مساعد يُنشأ فقط إذا لم يكن موجودًا، مع الحفاظ على أي تاريخ تدقيق سابق.

ملف الإصلاح التكميلي:
`migrations/0003_library_specialty_section_repair.sql`

يضيف `primary_section_id` إلى جدول التخصصات، ويربط التخصصات الأربعة عشر بالأقسام، ويضيف الفهرس وحواجز Trigger. هذا الفصل مقصود حتى لا تحاول Migration 0003 إضافة عمود موجود مسبقًا في قواعد التثبيت الجديدة.

## 2. حواجز الأمان

- لا يضيف أي عمود إلى `articles`.
- لا يغيّر `category` أو `tags_json` أو المحتوى أو التاريخ أو SEO.
- لا ينفذ أي `UPDATE` أو `DELETE` أو `ALTER TABLE articles`.
- لا يضيف أي صف إلى `library_article_classification`؛ لذلك لا يصنّف المقالات تلقائيًا.
- لا يحذف أو يعيد تسمية قيم التصنيف القديمة.
- لا يُعاد إنشاء `library_content_types` ولا تُستبدل بياناتها الموجودة؛ يستخدم التأسيس `INSERT OR IGNORE` فقط. قد تحتوي قاعدة قديمة على ستة أنواع بدل الخمسة الأساسية، ويجب الحفاظ عليها جميعًا.
- لا تشغّل Migration 0002 على قاعدة قديمة تحتوي الجداول بالفعل باعتبارها ترحيل إصلاح؛ استخدم Migration 0003 فقط إذا كانت الجداول الأساسية موجودة والعمود مفقودًا.
- التشغيل محصور في `alabqri-db-preview-test` بعد نسخة احتياطية، وممنوع تشغيله على قاعدة الإنتاج في هذه المرحلة.

## 3. ترتيب التطبيق

### قاعدة جديدة
1. خذ نسخة احتياطية وتحقق من اسم قاعدة Preview.
2. طبّق Migration 0002 مرة واحدة.
3. طبّق Migration 0003 مرة واحدة.
4. نفّذ استعلامات التحقق.

### قاعدة قديمة تحتوي جداول التصنيف
1. خذ نسخة احتياطية وتحقق من بنية الجداول.
2. إذا كان `library_specialties.primary_section_id` غير موجود، طبّق Migration 0003 فقط.
3. لا تعِد تطبيق Migration 0002 على قاعدة مأهولة.

## 5. نقاط لا تزال تحتاج اعتمادًا تحريريًا

- تخصص مقال الأذكار غير محسوم؛ لا يوجد تخصص مباشر له في قائمة الأربعة عشر.
- التخصص الدقيق لمقال «رحلة الشفاء الذاتي» يحتاج مراجعة علمية.
- سجلّا الخوف والخشية يحتاجان قرارًا بشأن العنوان والتداخل دون حذف.
- سجل رسالة المركز يحتاج قرار نقله إلى صفحة مؤسسية مستقلة.
- وسوم مقال الذنب وجلد الذات تحتاج اعتمادًا قبل تحديثها.
- لا يُسند أي مقال إلى قسم الحديث الشريف لمجرد وجود استشهاد بحديث.

# معيار المحتوى والحوكمة — مجلس العبقري للذكر والتسبيح

## الغرض
توحيد إدخال الأذكار والأدعية والآيات، ومنع التكرار، وحماية النصوص الشرعية من النقص أو النسبة غير الموثقة.

## سجل المادة
كل مادة مستقبلًا يجب أن تتضمن:
- معرفًا ثابتًا لا يتغير عند تعديل العنوان.
- النص الكامل كما في مصدره، مع ضبطه ومراجعته.
- نوع المادة: قرآن، حديث مرفوع، أثر، دعاء عام، شرح، أو مادة تعليمية.
- التصنيف الموضوعي، والكلمات المفتاحية.
- المصدر الدقيق: اسم الكتاب، الباب أو رقم الحديث، والسورة ورقم الآية عند الاقتضاء.
- حكم الحديث مع اسم من نقل الحكم ومرجعه، عند وجود حديث.
- العدد والوقت والسبب فقط إذا ثبتت في الدليل.
- حالة المراجعة، واسم/صفة المراجع، وتاريخ المراجعة، ورقم الإصدار.

## حالات النشر
1. مسودة: لا تظهر للزوار.
2. مراجعة نصية: مطابقة النص والرسم والضبط.
3. مراجعة تخريج: فحص المصدر والدرجة واختلاف الروايات.
4. مراجعة فقهية عند وجود حكم أو تخصيص.
5. معتمدة للنشر.
6. مؤرشفة أو مصححة، مع الاحتفاظ بسجل التغيير.

## قواعد لا يجوز تجاوزها
- لا يُنشأ حديث أو مصدر أو رقم تخريج بالتخمين.
- لا يُنسب عدد تعبدي أو فضل خاص إلى السنة بلا دليل.
- يميّز الذكر المطلق عن المقيد بوقت أو سبب.
- لا يُختصر نص قرآني أو حديث معروض بوصفه نصًا كاملًا.
- لا تُعرض المادة غير المحققة على أنها معتمدة.
- الأهداف الشخصية في العداد تنظيم اختياري ولا تعني سنة أو ثوابًا مخصوصًا.
- لا تقدم الرقية بوصفها بديلًا عن الرعاية الطبية.
- تُراعى حقوق النشر للتسجيلات والشروح والكتب.

## بنية البيانات المقترحة
`id, type, category, title, text, source, grading, count, timing, occasion, explanation, keywords, review_status, reviewer, reviewed_at, version`

## معايير القبول التقني
- عزل CSS/JS تحت مساحة قسم السبحة.
- عدم تغيير العداد القديم أو واجهات الإدارة.
- التعامل الآمن مع تعذر localStorage.
- دعم لوحة المفاتيح وقارئات الشاشة.
- اختبار عرض الكمبيوتر والهاتف.
- عدم نشر أي نص غير مكتمل أو غير موثق.

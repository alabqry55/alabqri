# مواصفات مكتبة العبقري — المرحلة الأولى

## الهدف
تحويل عرض المقالات الموحد إلى مكتبة مقسمة موضوعيًا، مع الإبقاء على سجلات D1 الحالية وآلية OAuth الخاصة بالمالك.

## الأقسام الظاهرة
1. القرآن الكريم وعلومه — قسم تمهيدي بحالة «قريبًا» حتى تتوفر مواد مصنفة له.
2. الذكر والاتزان الإيماني — مرتبط مؤقتًا بالتصنيف المخزن «الأذكار والاتزان».
3. علم النفس الإسلامي والتنمية البشرية — مرتبط بالتصنيف المخزن «التنمية البشرية».
4. الطب التكميلي والتوعية الصحية — مرتبط بالتصنيف المخزن «الطب التكميلي».
5. الأبحاث والدراسات — مرتبط بالتصنيف المخزن «البحث العلمي».
6. المعرفة والفكر — مرتبط بالتصنيف المخزن «موضوعات معرفية».

## وظائف المرحلة الأولى
- بطاقات أقسام تفاعلية تعرض عدد المواد.
- بحث فوري في العنوان والملخص والمحتوى والتصنيف والوسوم.
- تصفية بحسب القسم.
- استمرار عرض المقالات من واجهة API الحالية.
- استمرار تحرير المقالات وجدولتها عبر جلسة GitHub OAuth للمالك.

## توافق البيانات
لا تغيّر هذه المرحلة مخطط D1 ولا قيم التصنيف الخمس المقبولة من API. أسماء الأقسام الجديدة هي تسميات عرض فقط، مع ربط كل قسم بالتصنيف القديم المقابل. قسم القرآن يظهر «قريبًا» ولا يسمح بإنشاء تصنيف جديد قبل مرحلة ترحيل بيانات مستقلة واختبارها.

## خارج نطاق هذه المرحلة
- لا تعديل لقاعدة البيانات أو حذف سجلات.
- لا تغيير لصلاحيات الإدارة أو تدفق OAuth.
- لا نشر إلى الإنتاج قبل مراجعة المعاينة ونجاح اختبارات الأمان والانحدار.
- لا اعتماد ادعاءات علاجية في المحتوى الصحي دون دليل موثوق.
